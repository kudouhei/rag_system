# 钓鱼邮件与反垃圾邮件处理（Phishing & Anti-Spam）

## 1. 识别可疑邮件的常见特征
- 发件人域名与公司/知名品牌高度相似但有细微差别（如多一个字母）
- 邮件中包含紧急语气（要求立刻转账/修改密码/点击链接验证账号）
- 附件为可执行文件或宏文档，或链接指向非公司域名的登录页

## 2. 收到可疑邮件的处理步骤
1. 不要点击链接、不要下载附件、不要回复
2. 使用邮件客户端的"举报钓鱼"功能，或转发至安全团队邮箱
3. 如已点击链接或输入过密码：立即修改该账号密码，并检查是否需要强制下线所有会话
4. 如涉及财务转账类钓鱼（BEC，商业邮件诈骗），需立即通知财务与安全团队核实

## 3. 是否升级为安全事件
- 仅收到但未点击/未泄露信息：记录并加入黑名单即可，无需升级
- 已点击链接输入凭据、或已执行附件：升级为疑似账号泄露事件，按数据泄露应急流程评估影响范围
- 涉及批量员工收到同一钓鱼邮件（定向攻击迹象）：升级为安全事件并全员预警

## 4. 反垃圾邮件网关
- 邮件网关会自动拦截已知恶意域名/附件特征，误拦截可提交白名单申请
- 定期更新钓鱼特征库，结合员工举报数据优化拦截规则

## 5. 安全意识培训
- 定期开展模拟钓鱼演练，统计点击率作为安全意识指标
- 多次未通过演练的员工需参加额外安全培训
