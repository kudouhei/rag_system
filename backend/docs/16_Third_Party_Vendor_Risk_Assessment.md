# 第三方供应商风险评估（Vendor Risk Assessment）

## 1. 适用场景
- 引入新的 SaaS 工具、外部数据处理服务商、外包开发团队
- 供应商需要访问公司数据（尤其是 L2/L3 敏感数据）或系统

## 2. 评估维度
- **数据安全**：是否有 SOC2/ISO27001 等认证，数据加密与隔离方案
- **访问范围**：供应商需要的最小访问权限是什么，是否可审计
- **合规性**：是否涉及跨境数据传输，是否符合 GDPR 等法规要求
- **业务连续性**：供应商的 SLA、灾备能力、是否存在单点依赖

## 3. 评估流程
1. 业务方提交供应商接入申请，说明用途与数据范围
2. 安全团队进行风险评估问卷 + 尽职调查
3. 法务审核数据处理协议（DPA）与合同条款
4. 根据风险等级决定是否需要额外的技术控制（如数据脱敏、专用网络隔离）

## 4. 生产数据访问的额外要求
- 供应商原则上不得直接访问生产数据库
- 确需访问时，必须通过脱敏/最小化字段的方式，且限定时间窗口
- 所有访问需记录审计日志，定期复核是否仍有必要

## 5. 定期复审
- 高风险供应商每年至少复审一次
- 供应商发生安全事件（自身被攻破）需立即触发临时复审
