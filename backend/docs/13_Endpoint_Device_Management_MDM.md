# 终端设备管理与 MDM 合规（Endpoint / MDM）

## 1. 设备注册（Enrollment）
- 新设备（公司配发的笔记本/手机）必须在到手 3 天内完成 MDM 注册
- 注册流程：IT 门户领取激活码 → 安装 MDM Profile → 自动下发基线策略

## 2. 合规基线策略（Compliance Baseline）
- 磁盘加密（FileVault/BitLocker）必须开启
- 系统版本落后官方最新版本不超过 2 个大版本
- 必须安装公司指定的 EDR/杀毒软件并保持运行
- 屏幕锁定超时 ≤ 10 分钟

## 3. 不合规设备的处理
- 首次检测到不合规：推送提醒，7 天整改期
- 逾期未整改：自动限制访问公司邮箱/VPN 等敏感系统（Conditional Access）
- 高风险不合规（如越狱/root）：立即隔离，需安全团队人工介入

## 4. 个人设备（BYOD）
- 仅允许访问邮箱与即时通讯类低敏系统
- 不允许访问代码仓库、生产系统、财务系统
- 需安装轻量级 MDM Profile 并同意远程擦除受管理数据的授权

## 5. 离职/丢失处理
- 离职当天：远程擦除设备上的公司数据，回收 MDM Profile
- 设备丢失/被盗：立即上报 IT，触发远程锁定与擦除
