# 软件许可证与资产管理（License & Asset Management）

## 1. 软件采购流程
- 提交采购申请：软件名称、用途、预计使用人数、预算
- 涉及处理敏感数据的第三方软件，需同步走供应商风险评估
- IT 审核是否已有可用许可证（避免重复采购）后再走财务审批

## 2. 许可证类型
- 按席位（Per-seat）：每个使用者需要一个独立许可证
- 按设备（Per-device）：绑定具体设备而非人
- 站点许可（Site License）：公司范围内不限数量使用

## 3. 续期与到期提醒
- 系统在到期前 30/14/7 天自动提醒许可证 Owner
- 到期未续期的许可证会被自动禁用，相关用户会收到通知
- 续期需重新确认使用人数是否有变化，避免超额使用

## 4. 资产台账
- IT 资产管理系统记录：设备/软件的负责人、部门、采购日期、到期日期
- 员工离职需交还设备并解绑相关软件许可证
- 定期（每季度）盘点软件使用率，清退长期未使用的许可证以节省成本

## 5. 合规风险
- 禁止使用未经采购流程的破解版/个人版软件处理公司业务数据
- 发现违规使用需立即下架并按内部合规流程处理
